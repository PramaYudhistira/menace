## What is Menace CLI?

Menace CLI is a cross-platform, terminal-based intelligent assistant that leverages large language models (LLMs) to provide context-aware assistance directly in your terminal. Built with Go for performance and Node.js for cross-platform compatibility, it offers an interactive text user interface (TUI) powered by Bubble Tea.

### Key Features

- **Cross-Platform Support**: Native binaries for Windows, macOS (Intel & Apple Silicon), and Linux
- **Interactive TUI**: Rich text user interface with mouse support and syntax highlighting
- **LLM Integration**: Context-aware AI assistance using OpenAI and Anthropic models
- **Command Suggestions**: Intelligent shell command recommendations
- **Code Assistance**: Read, write, and navigate code with AI help
- **Modern Architecture**: Built with Go's performance and Node.js ecosystem benefits

### Quick Start

```bash
# Install from npm (coming soon)
npm install -g menace-cli

# Set your API key
export OPENAI_API_KEY="your_api_key_here"

# Launch Menace
menace
```
