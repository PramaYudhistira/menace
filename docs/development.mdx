# Development Guide

This guide covers setting up a development environment, understanding the codebase, and contributing to Menace CLI.

## Development Environment Setup

### Prerequisites

**Required Tools:**
- **Go**: Version 1.18 or higher
- **Node.js**: Version 14 or higher
- **npm**: Version 6 or higher
- **Git**: For version control

**Optional but Recommended:**
- **Go extension for VS Code** or your preferred Go IDE
- **gopls**: Go Language Server
- **golangci-lint**: Linting tool

### Initial Setup

1. **Fork and Clone:**
   ```bash
   git clone https://github.com/your-username/menace-cli.git
   cd menace-cli
   ```

2. **Install Dependencies:**
   ```bash
   cd menace-cli
   npm install
   ```

3. **Install Go Dependencies:**
   ```bash
   cd src
   go mod download
   go mod tidy
   ```

4. **Set Up API Key:**
   ```bash
   export OPENAI_API_KEY="your-development-api-key"
   ```

5. **Build and Test:**
   ```bash
   npm run build
   npm link  # For local testing
   ```

### Code Architecture

#### 1. Entry Point (`main.go`)

The application bootstrap process:

```go
func main() {
    // Environment validation
    apiKey := os.Getenv("OPENAI_API_KEY")
    if apiKey == "" {
        fmt.Println("Error: OPENAI_API_KEY environment variable not set")
        os.Exit(1)
    }

    // Agent initialization
    agent, err := llmServer.NewAgent(apiKey)
    if err != nil {
        fmt.Printf("Error initializing agent: %v\n", err)
        os.Exit(1)
    }

    // UI initialization with Bubble Tea
    zone.NewGlobal()
    p := tea.NewProgram(
        ui.NewModel(agent),
        tea.WithAltScreen(),
        tea.WithMouseAllMotion(),
    )

    if _, err := p.Run(); err != nil {
        fmt.Println("Error running Menace CLI:", err)
        os.Exit(1)
    }
}
```

#### 2. LLM Server Layer (`llmServer/`)

**Agent (`agent.go`):**
- Primary interface between UI and LLM providers
- Manages conversation context and history
- Handles function calling and command suggestions

```go
type Agent struct {
    llm      llms.Model           // LangChain LLM interface
    mu       sync.Mutex          // Thread safety
    shell    string              // Detected shell environment
    messages []llms.MessageContent // Conversation history
    ctx      context.Context     // Request context
    provider string              // Current LLM provider
    Model    string              // Current model name
}
```

**LLM Service (`llmService.go`):**
- Singleton pattern for API management
- HTTP client configuration and request handling
- Model switching and configuration

#### 3. UI Layer (`ui/`)

**Model (`model.go`):**
- Central state management following Bubble Tea patterns
- Input handling, cursor management, and text selection
- Integration with clipboard operations

```go
type Model struct {
    Input    string              // Current input text
    Messages []Message           // Chat history
    agent    *llmServer.Agent    // LLM agent reference
    Width    int                 // Terminal width
    Height   int                 // Terminal height
    Scroll   int                 // Chat scroll position
    
    // Cursor and selection state
    CursorX     int
    CursorY     int
    WindowStart int
    
    // UI state
    IsThinking   bool
    IsConfigOpen bool
    
    // Command approval workflow
    PendingCommand          *CommandSuggestionMsg
    AwaitingCommandApproval bool
}
```

### Code Style and Standards

#### Go Code Guidelines

**Formatting:**
```bash
# Format code
go fmt ./...

# Lint code
golangci-lint run
```

**Naming Conventions:**
- Use camelCase for private functions and variables
- Use PascalCase for exported functions and types
- Use descriptive names for complex logic

**Error Handling:**
```go
// Good: Explicit error handling
result, err := someOperation()
if err != nil {
    return fmt.Errorf("operation failed: %w", err)
}

// Avoid: Ignoring errors
result, _ := someOperation() // Bad
```

**Concurrency:**
```go
// Always protect shared state
func (s *LLMService) SendMessage(input string) error {
    s.mu.Lock()
    defer s.mu.Unlock()
    // ... safe operations
}
```

#### JavaScript/Node.js Guidelines

**File Structure:**
- Use consistent indentation (2 spaces)
- Include error handling for all async operations
- Use modern JavaScript features (ES6+)

### Adding New Features

#### 1. Adding a New LLM Provider

1. **Create provider client** in `llmServer/`:
```go
// anthropic.go
func NewAnthropicClient(apiKey string) (llms.Model, error) {
    return anthropic.New(
        anthropic.WithToken(apiKey),
        anthropic.WithModel("claude-3-sonnet-20240229"),
    )
}
```

2. **Update agent initialization** in `agent.go`:
```go
func NewAgent(apiKey string, provider string) (*Agent, error) {
    var llm llms.Model
    var err error
    
    switch provider {
    case "openai":
        llm, err = openai.New(...)
    case "anthropic":
        llm, err = NewAnthropicClient(apiKey)
    default:
        return nil, fmt.Errorf("unsupported provider: %s", provider)
    }
    // ... rest of initialization
}
```

3. **Add configuration support**:
```go
// Add environment variable support
provider := os.Getenv("MENACE_PROVIDER")
if provider == "" {
    provider = "openai"
}
```

#### 2. Adding UI Components

1. **Create component in `ui/`**:

```go
func (m SettingsModel) Init() tea.Cmd {
```

2. **Integrate with main model** in `model.go`:

3. **Update view rendering** in `view.go`:

```go
func (m Model) View() string {

```

#### 3. Adding Command Functions

1. **Define function in `llmServer/`**:
```go
// functions.go
type FileOperation struct {
    Path    string `json:"path"`
    Content string `json:"content"`
}

func ExecuteFileOperation(op FileOperation) error {
    return ioutil.WriteFile(op.Path, []byte(op.Content), 0644)
}
```

2. **Register with agent**:
```go
// In agent.go, add to function definitions
functions := []llms.FunctionDefinition{
    {
        Name:        "file_operation",
        Description: "Write content to a file",
        Parameters: map[string]interface{}{
            "type": "object",
            "properties": map[string]interface{}{
                "path":    map[string]string{"type": "string"},
                "content": map[string]string{"type": "string"},
            },
            "required": []string{"path", "content"},
        },
    },
}
```

```go
    switch msg := msg.(type) {
    case tea.KeyMsg:
        if msg.String() == m.lastKey {
            return m, nil // No change
        }
        m.lastKey = msg.String()
    }
    // ... handle update
}
```
