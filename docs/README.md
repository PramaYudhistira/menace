## 🚀 Quick Start

1. **Install Menace CLI**:
   ```bash
   npm install -g menace-cli
   ```

2. **Set up your API key**:
   ```bash
   export OPENAI_API_KEY="your-api-key-here"
   ```

3. **Launch the assistant**:
   ```bash
   menace
   ```
